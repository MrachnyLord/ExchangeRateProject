# База даних у проєкті

Курси зберігаються в SQL Server LocalDB, база називається CurrencyRatesDb, таблиця — Rates.

## Як це влаштовано

Застосунок бере курси з API (НБУ, ПриватБанк, монобанк), обробляє їх у `ExchangeRateService` і записує в таблицю Rates. Потім головна сторінка, історія і конвертер читають дані вже з бази, а не напряму з інтернету кожного разу.

Вручну в SQL нічого вставляти не потрібно.

## Таблиця Rates

У таблиці такі поля:

- Id — номер запису
- BankName — назва банку або «НБУ»
- CurrencyCode — USD або EUR
- BuyRate — курс купівлі
- SellRate — курс продажу
- FetchDate — коли цей запис збережено

Кожне оновлення додає нові рядки, старі не перезаписуються. Наприклад, о 10:00 збереглось 8 записів, о 10:05 — ще 8. Так і формується історія.

## Коли дані потрапляють у базу

1. При запуску програми (F5), якщо сьогодні ще немає свіжих курсів.
2. У фоні кожні 60 хвилин — працює `ExchangeRateBackgroundService`.
3. Коли натиснути «Оновити» на головній сторінці.

Старі записи (більше 90 днів) видаляються автоматично.

## Налаштування в appsettings.json

```json
"ExchangeRateSync": {
  "AutoSyncEnabled": true,
  "RefreshIntervalMinutes": 60,
  "HistoryRetentionDays": 90,
  "StartupDelaySeconds": 3
}
```

Якщо поставити AutoSyncEnabled в false, фонове оновлення вимкнеться, залишиться тільки старт і кнопка «Оновити».

## Як сторінки використовують базу

Головна показує останні курси за сьогодні з таблиці Rates. Історія бере курси за обрану дату. Конвертер для НБУ ходить напряму в API, а для ПриватБанку і монобанку — у базу за сьогоднішніми даними.

## Подивитись дані вручну

У Visual Studio: View → SQL Server Object Explorer → (localdb)\MSSQLLocalDB → CurrencyRatesDb → Tables → dbo.Rates

Приклад запиту:

```sql
SELECT TOP 20 BankName, CurrencyCode, BuyRate, SellRate, FetchDate
FROM Rates
ORDER BY FetchDate DESC;
```

## Часті питання

**Таблиця швидко росте?** Так, кожні 5 хвилин додається новий знімок. Для курсового це нормально, старе само чиститься.

**Конвертер пише що курси не завантажені?** Треба спочатку запустити застосунок і почекати кілька секунд, або натиснути «Оновити» на головній.

**Історія порожня?** Вона з'явиться після першого збереження курсів.
